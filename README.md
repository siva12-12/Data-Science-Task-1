# CodeAlpha Data Science Internship Projects

This repository contains the data science projects completed as part of the **CodeAlpha Data Science Internship**.

---

## 📁 Projects Overview

### ✅ Task 1: Iris Flower Classification

**Objective:** Classify Iris flower species (Setosa, Versicolor, Virginica) based on sepal and petal measurements.

**Dataset:** Iris.csv (150 samples, 4 features)

**Approach:**
- Exploratory Data Analysis with visualizations (pairplot, boxplot, heatmap)
- Trained 5 ML models: Logistic Regression, Decision Tree, Random Forest, SVM, KNN
- Evaluated using Accuracy, Classification Report, Confusion Matrix

**Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

**Result:** Achieved up to **100% accuracy** using SVM / KNN

---

### ✅ Task 2: Car Price Prediction with Machine Learning

**Objective:** Predict the selling price of used cars based on features like present price, driven kilometers, fuel type, transmission, and car age.

**Dataset:** car_data.csv

**Approach:**
- Feature Engineering: Created `Car_Age` from manufacturing year
- Encoded categorical features (Fuel Type, Transmission, Selling Type)
- Trained 4 regression models: Linear Regression, Decision Tree, Random Forest, Gradient Boosting
- Evaluated using R² Score, MAE, RMSE

**Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

**Result:** Random Forest / Gradient Boosting achieved the **best R² score**

---

### ✅ Task 3: Sales Prediction using Python

**Objective:** Predict product sales based on advertising spend across TV, Radio, and Newspaper channels.

**Dataset:** Advertising.csv (200 samples)

**Approach:**
- Analyzed correlation between ad channels and sales
- Visualized ad spend distribution and impact on sales
- Trained 4 regression models: Linear Regression, Decision Tree, Random Forest, Gradient Boosting
- Evaluated using R² Score, MAE, RMSE

**Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

**Result:** **TV advertising** has the highest impact on sales
